בונה סקילים

הופך תהליך שאתם עושים שוב ושוב לסקיל חדש משלכם, כולל בדיקות שהוא באמת עובד. הסקיל הרשמי של Anthropic.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

יש משהו שאתם מסבירים לקלוד שוב ושוב? הסקיל הזה הופך את ההסבר לסקיל קבוע: קלוד מבין מה התהליך, כותב את הסקיל, ומודד שהוא עובד טוב עם בדיקות.

יודע גם לשפר סקיל קיים ולדייק את תיאור ההפעלה שלו, כדי שקלוד ידע מתי להשתמש בו.

מתי זה שימושי

  • הפיכת תהליך עבודה חוזר לסקיל קבוע
  • שיפור סקיל קיים שלא מופעל נכון
  • בדיקת סקיל חדש לפני שמשתמשים בו באמת
  • אריזת ידע מקצועי לסקיל שאפשר לחלוק

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תהפוך את התהליך הזה לסקיל"
  • "תשפר לי את הסקיל הקיים"
  • "תבנה סקיל שעושה את מה שהראיתי לך"

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "בונה סקילים" (skill-creator).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ai-shiralon.github.io/claude-skills/dl/skill-creator.tar.gz
3. חלץ ממנה את התיקייה skills/skill-creator אל ~/.claude/skills/skill-creator. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: דוגמה לתהליך שרוצים להפוך לסקיל. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תהפוך את התהליך הזה לסקיל".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ai-shiralon.github.io/claude-skills/install.sh | bash -s -- skill-creator

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
