התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "מסמכי Word מקצועיים" (docx).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ai-shiralon.github.io/claude-skills/dl/docx.tar.gz
3. חלץ ממנה את התיקייה skills/docx אל ~/.claude/skills/docx. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python בסביבת העבודה. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תכתוב לי את זה כמסמך וורד מסודר".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ai-shiralon.github.io/claude-skills/install.sh | bash -s -- docx

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
