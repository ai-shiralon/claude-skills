עבודה עם PDF

קורא, מחלץ, ממזג, מפצל ויוצר קבצי PDF, כולל טפסים, חתימות מים וסריקות. הסקיל הרשמי של Anthropic.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

הסקיל הרשמי של Anthropic לכל עבודה עם PDF: חילוץ טקסט וטבלאות, מיזוג כמה קבצים לאחד, פיצול, סיבוב עמודים, הוספת סימני מים ויצירת PDF חדש מאפס.

יודע גם למלא טפסי PDF, להצפין ולפתוח הצפנה, לחלץ תמונות, ולהפוך מסמך סרוק לחפיץ עם OCR.

מתי זה שימושי

  • חילוץ טבלה מדו״ח PDF לאקסל
  • מיזוג חשבוניות נפרדות לקובץ אחד
  • מילוי טופס PDF רשמי
  • הפיכת מסמך סרוק למסמך עם חיפוש

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תחלץ לי את הטקסט מה-PDF הזה"
  • "תמזג את שלושת הדוחות לקובץ אחד"
  • "תמלא לי את הטופס הזה"

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "עבודה עם PDF" (pdf).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://ai-shiralon.github.io/claude-skills/dl/pdf.tar.gz
3. חלץ ממנה את התיקייה skills/pdf אל ~/.claude/skills/pdf. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python בסביבת העבודה. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תחלץ לי את הטקסט מה-PDF הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://ai-shiralon.github.io/claude-skills/install.sh | bash -s -- pdf

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
